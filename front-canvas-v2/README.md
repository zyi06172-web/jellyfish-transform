# 女娲 · 无限画布（front-canvas）

全新独立前端工程，不影响 `front/`（旧前端）与 `backend/`（后端完全未改动）。

## 怎么启动

```bash
cd front-canvas
pnpm install
pnpm run dev
```

打开 <http://localhost:7799>。

**必须先把后端跑起来**，默认直连 `http://127.0.0.1:8000`。如果后端跑在别的地址，新建 `.env.local`：

```
VITE_BACKEND_URL=http://你的后端地址:端口
```

如果后端 API 有变化，重新生成一次接口 client（需要后端正在本机运行）：

```bash
pnpm run openapi:update
```

## 怎么操作（第二轮修改单后的形态：永久暗色，无顶栏，左侧竖栏）

1. **首页**：点「创建画布」（会新建一个后端项目，一个项目=一张画布，见下方"已知简化"）。
2. **左侧竖栏**（替代已删除的顶栏）：从上到下 —
   - **白色圆形加号** → 打开"添加节点"菜单（也可以双击画布空白处、或从节点连接点拖线到空白处触发）。
   - **资产库**（方块图标）→ 项目资产 / 素材库 / 回收站 三 tab，含搜索、类型筛选、大中小三视图、回收站还原/彻底删除/清空。
   - **预设工作流**（图层图标）→ 两张卡片，点一张一键把整套节点+连线铺到画布上（见第 3、4 点）。
   - **历史记录**（时针图标）→ 图片历史 / 视频历史两 tab，点缩略图聚焦到对应节点。
   - **底部彩虹小球** → 女娲 Agent，点开右侧引导面板，贴剧本推进短剧流程。
3. **短剧工作流**（预设工作流里第一张卡）：点卡片铺开 剧本 → 角色/场景/道具 → 手绘故事板 → 文字分镜表 → 关键帧 → 渲染分镜表 → 视频 整条链；再用左下女娲 Agent 贴剧本推进。真出图/出视频前保留成本确认弹窗。
4. **电商工作流**（预设工作流里第二张卡，"服装·亚马逊 A+ 详情"）：点卡片铺开整套 A+ 详情素材节点（商品 / 场景分析 / 场景图×3 / 卖点图×3 / 细节·面料·尺码 / A+ 五图）。每个生图节点已预置专业英文电商摄影 prompt，点节点 → 对话框 → 「生成」即走火山 Seedream **真出图**。商品节点还能上传原图当参照。
5. **每个生成对话框左上角显示真实积分余额**，点它打开充值页（四套餐 / 支付方式 / 金额联动；支付本轮占位）。生成会真实扣积分。
6. **节点连线**：节点左右是「圆圈+加号」连接点，靠近会放大；长按拖出黑线+彩虹流光，落空白处弹菜单建新节点并连线，落到别的节点加号则直接关联；双击连线剪断。
7. **便签 / 上传**：添加节点菜单里 —「便签」是白色专业纸条，双击编辑，内容可被其它节点用 `@` 引用；「上传」选本地图片/视频，真传到后端存储，生成一个可连线的素材节点。
8. **删除节点**：右键 → 删除，二次确认。只有你自己删的会消失，系统不自动删生成结果。

## 目录速览

```
src/
  pages/Canvas/        画布外壳（LeftRail/各面板/充值页）、CanvasBoard、hooks
  components/nodes/    16 种节点（4 通用 + 10 短剧 + 商品 + 便签 + 素材）
  components/agent/    女娲 Agent 右侧引导面板
  components/edges/    彩虹流光边 + 拖线连接线
  services/            OpenAPI client + canvas-state / 生成链路 / 积分 / 上传封装
  types/               节点类型、模型清单、预设工作流定义、Recipe
```

## 已知简化（不是 bug，是本轮明确的简化）

- 后端没有独立"画布"实体与 `/canvases` 接口 → 一个后端项目 = 一张画布。
- 后端没有积分接口 → 积分走前端本地账本（会随生成扣减、随充值联动预览），充值页标注"本地账本"。
- 通用图片节点/电商生图节点用后端"道具(prop)"资产的图片槽位做真实 Seedream 出图的载体（后端无"不挂实体的自由生图"接口）。

完整的诚实缺口清单见 `DELIVERY_NOTES.md`。
