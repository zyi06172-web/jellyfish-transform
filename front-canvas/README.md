# 女娲 · 无限画布（front-canvas）

全新独立前端工程，不影响 `front/`（旧前端）与 `backend/`（后端完全未改动）。

## 怎么启动

```bash
cd front-canvas
pnpm install
pnpm run dev
```

打开 <http://localhost:7799>。

**必须先把后端跑起来**，默认直连 `http://127.0.0.1:8000`。如果后端跑在别的地址，新建 `.env.local`：

```
VITE_BACKEND_URL=http://你的后端地址:端口
```

如果后端 API 有变化，重新生成一次接口 client（需要后端正在本机运行）：

```bash
pnpm run openapi:update
```

## 怎么操作

1. **首页**：点「创建画布」（会新建一个后端项目，一个项目=一张画布，见下方"已知简化"）。
2. **顶栏**：左侧可切「专业 AIGC 画布 / 专业电商画布 / 自定义画布」；项目名点一下就能改；比例/分辨率是全局默认值；右侧显示预估累计花费、女娲积分（占位）、设置、明暗切换、引导面板开关。
3. **短剧 workflow（专业 AIGC 画布）**：
   - 在右侧引导面板贴入剧本原文，跟着问答走：剧本解析 → 人物/场景/道具资产 → 6 格手绘故事板。
   - 故事板生成后，画布上会自动出现「分镜表（文字版）」节点——这是免费预审，点「开始渲染」会先弹出成本确认（张数 + 预估金额 + 模型），确认后才真正调用生图。
   - 关键帧节点里每张图都能单独重渲（右上角小图标），全部重渲会新开一个节点、旧的保留。
   - 关键帧完成后，点节点上的表格图标生成「渲染版分镜表」，再点「确认，开始出视频」——同样先有成本确认弹窗，确认后才调用 Seedance。
   - 视频节点可以直接播放和下载。
4. **专业电商画布**：右键或双击空白处新建「商品节点」，填商品名称/描述，上传原图，点「生成产品设定图（白底）」「生成多角度」——这两步是真实调用后端生成的（复用了后端的"道具"资产类型，见 `src/services/ecommerceRuntime.ts` 顶部注释）。场景合成/详情页排版/营销海报这几步目前只是占位。
5. **自定义画布**：没有引导面板，只有中下角的紫色小球——点它展开对话框，拖它会挪位置。画布本身完全自由：双击建节点、拖连接点连线、双击连线剪断。
6. **资产库**：顶栏那个小图标，从左边滑出，接的是现有的 `asset-library` 接口。
7. **删除节点**：右键 → 删除，会二次确认。只有你自己删的节点会消失，系统不会自动删任何生成结果。

## 目录速览

```
src/
  pages/Canvas/        画布页外壳、顶栏、资产库抽屉、设置弹窗、各种 hooks
  components/nodes/    十四种节点组件（4 通用 + 10 短剧 workflow + 1 商品）
  components/agent/    双形态 agent（小球 / 引导面板）
  services/            OpenAPI 生成的 client + 手写的 canvas-state/生成链路封装
  types/                节点数据类型、模型清单、canvasType 配置
```

## 已知简化（不是 bug，是本轮明确的简化）

- 后端目前没有独立的"画布"实体，也没有 `/canvases` 列表接口——这里用「一个后端项目 = 一张画布」。
- 电商画布复用了后端的"道具（prop）"资产类型来承担"商品"，因为后端本来就没有商品实体。

完整的诚实缺口清单见 `DELIVERY_NOTES.md`。
